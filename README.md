## 0.1. Telegram-бот для уведомлений

**Условие запуска:** добавить бота, если после рекламы стабильный онлайн достигнет примерно **30 игроков**.

### Назначение
Бот отправляет уведомления в Telegram-канал о том, что кондо доступно, например в **09:00** и **16:00**. Если кондо заблокировано, бот не отправляет ссылку и не публикует сообщение.

### Команды настройки

| Команда | Назначение |
|---|---|
| `/link` | Изменить ссылку на профиль игрока, у которого находится кондо. |
| `/text` | Изменить шаблон уведомления. Пример: `Вышло новое кондо! Ссылка на профиль: [link]`. |
| `/banned` | Включить/выключить режим блокировки: при включении бот не публикует уведомления. |
| `/time list` | Показать список времени уведомлений. |
| `/time add [00:00]` | Добавить время для уведомления. |
| `/time remove [00:00]` | Удалить время уведомления. |

## 0.5. Мини-игры

1. **Sword Fight** — режим 1 на 1. После победы проигравший не умирает: у него остаётся 0,1 HP и включается Ragdoll. Для дальнейших ролевых действий использовать только добровольные взаимодействия с подтверждением обеих сторон, выбором анимации и предпросмотром на двух Dummy.
2. **Отгадай слово** — игроки отгадывают загаданное слово.
3. **Шашки** — сложная система; оставить на последний этап разработки.
4. **Догонялки** — один игрок становится ведущим и ловит остальных.

## 0.6. Модерация чата

### Модераторы

- AI-модерация.
- Ручная модерация доверенными сотрудниками.

### Ссылки

- Автоматически удалять любые ссылки из сообщений.
- Первое нарушение: мут на **5 минут**.
- Повторное нарушение: мут на **10 минут**.
- Все последующие нарушения: мут на **10 минут**.

### Спам и флуд

- Проверять повторяющиеся сообщения.
- Проверять поток случайных сообщений.
- Блокировать отправку спам-сообщений до публикации.
- При флуде или спаме выдавать мут на **5–10 минут** — в зависимости от тяжести нарушения.

## 0.8. Система парных интерактивных мест

- Игрок занимает Seat.
- Второй игрок может присоединиться только после подтверждения первого игрока.
- Открывается GUI с выбором и предпросмотром доступных анимаций на Dummy.
- GUI можно скрыть.
- У каждого участника должна быть кнопка немедленного выхода из взаимодействия.

### Права владельцев

В Custom Admin добавить безопасные инструменты управления сценой для Owner: например, завершение зависшей анимации или освобождение Seat. Нельзя запрещать игроку выйти, переродиться или использовать базовые функции Roblox.

### Защита от эксплойтов

Добавить серверную проверку: если клиент пытается телепортировать Seat или участника сцены, сервер отменяет действие и возвращает объект на корректную позицию.

## 1.0. Инструменты

### Общие/ролевые инструменты

- **HandCuffs** — инструмент для добровольной ролевой сцены или модерации. Должен работать только с согласием игрока и всегда позволять освободиться или покинуть сцену.
- **Эффект «Герыч»** — исключительно визуальный игровой эффект: пикселизация, размытие, покачивание камеры и мерцание. Не использовать реальные названия наркотиков и не связывать эффект с поощрением употребления веществ.

### Инструменты для администраторов

| Инструмент | Назначение |
|---|---|
| **Смена команды** | Быстро меняет команду игрока на одну из существующих. Если команд нет, GUI не открывается. |
| **Создание команды** | Создаёт и удаляет команды. Все действия логируются. |
| **Kick Tool** | Исключает выбранного игрока из сервера после подтверждения действия. |
