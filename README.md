## 0.1 — Бот в Telegram

Если после рекламы в ТГ будет нормальный онлайн и в кондо будет хотя бы примерно 30 игроков, можно будет сделать бота в ТГК.

Что должен делать бот:

- Каждый день в 09:00 писать в ТГК, что кондо ещё доступно.
- Потом ещё раз писать в 16:00.
- Если кондо заблокировали, бот ничего не пишет и ссылку не отправляет.

Команды для настройки бота:

- `/link` — поменять ссылку на профиль игрока, у которого находится кондо.
- `/text` — поменять текст, который бот будет отправлять. Пример: `Вышло новое кондо! Ссылка на профиль: [link]`.
- `/banned` — включить режим, когда кондо заблокировано и бот ничего не пишет.
- `/time list` — посмотреть всё время уведомлений.
- `/time add [00:00]` — добавить время.
- `/time remove [00:00]` — убрать время.

## 0.6 — Модерация в чате

Нужна AI-модерация и обычные модераторы из доверенных людей.

### Ссылки

- Автоматически удалять из чата любые ссылки.
- За первую ссылку — мут на 5 минут.
- Если игрок снова пытается отправить ссылку — мут на 10 минут.
- Все следующие нарушения — тоже мут на 10 минут.

### Спам и флуд

- Проверять одинаковые сообщения.
- Проверять спам из рандомных сообщений.
- Просто блокировать отправку спам-сообщений.
- За сильный флуд или спам выдавать мут от 5 до 10 минут — смотря что именно игрок писал.

## 0.7 — Команды для персонажей

Команды должны быть рабочими.

- `/char [name / ID]` — превратиться в любого игрока по имени или ID.
- `/cchar` — снять с себя персонажа игрока.
- `/achar [имя игрока] [name / ID]` — выдать персонажа другому игроку. Только для админов.
- `/cchar [name]` — снять персонажа с указанного игрока.

Также надо добавить нормальную интеграцию команд с Chat и Custom Admin.

## 0.8 — Парные места / «ковры»

Сделать рабочую систему парных мест.

Как это должно работать:

- Игрок садится на Seat.
- Второй игрок может присоединиться после подтверждения.
- Появляется GUI с Preview анимаций на Dummy.
- GUI можно скрыть.
- Любой игрок всегда может отменить взаимодействие и выйти.

Для Owner в Custom Admin можно добавить функции для управления такими сценами: например, освободить игрока с места или остановить зависшую анимацию.

Также нужен Anti-Cheat: если игрок через Local пытается телепортировать Seat или себя куда-то во время этой системы, сервер должен отменять это и возвращать всё обратно.

## 0.9 — Anti-BackDoor

Нужна серверная и локальная проверка.

Если игрок слишком быстро перебирает или вызывает все RemoteEvent/ивенты, которые есть в игре, ему должен выдаваться **Flag**. После этого ему временно блокируются опасные функции.

Админ должен видеть:

- Кто получил Flag.
- За что именно он его получил.
- Когда это произошло.
- Что игрок делал до этого.

После проверки админ уже решает, выдавать блокировку или нет.

## 1.0 — Tools, чтобы рофлить и для админов

### Обычные/ролевые Tools

- **HandCuffs** — инструмент, который надевает наручники. Использовать только в добровольных ролевых сценах или для модерации; у игрока должна быть возможность выйти из ситуации.
- **Эффект с пиксельным экраном** — Tool, который делает экран пиксельным, добавляет размытие, мерцание и покачивание камеры. После эффекта можно сделать респавн игрока.

---

### Tools для админов

- **Tool «Менять команду»** — быстро меняет команду игроку на одну из тех, что есть в игре. Если команд нет, GUI не открывается.
- **Tool «Создавать команду»** — позволяет создать любую команду и потом удалить её.
- **Kick Tool** — при нажатии на игрока кикает его с сервера.

Желательно, чтобы все действия админов логировались.
